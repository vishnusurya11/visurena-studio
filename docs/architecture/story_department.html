Visurena Studio · part one · book → screenplay

The Story Department

Seventeen agents, read as a company. Code is management: every step script decides the order, hands out briefs, assembles, counts and checks. Agents are specialists: each gets one brief and returns one typed object. Nobody edits a file; nobody reads another agent's answer. The chart below is who reports to whom; the flow after it is one book going through a typical run.

leader (code: a runner or step script) agent, workhorse tier agent, reasoning tier QC agent: judges work, never the book

Run log

The dashed return arrows are the three improve loops. Each is capped at two rounds; the run shown takes one round in Extract (the auditor flags one chapter's dialogue, and only that specialist is re-run). Nothing in this stage spends money on media; every call is a text model on the workhorse or reasoning tier.
