## How a row is derived

- For every registry step, `outputs_of(stage, step, unit)` matched on disk says whether it has
  written; `progress` counts the steps with every declared output present.
- `done` when the department's deliverable exists: the registry's (`manifest.json`), else the
  pre-manifest episode pair -- a master under `cut/` beside a `qc_r2v.json` that passed.
- `deferred` when `plan.deferred.json` exists and no `plan.verdict.json` beside it.
- otherwise `blocked`, at the last step with an output OF THIS UNIT (a step whose outputs are all
  book-level -- bind's `refs.json`, the shared places -- does not move the pointer).
- verdicts and flags through `studio.verdict_rows`; GPU seconds through `studio.timing_sum`;
  attempts and clocks from the events when the unit has any (WotW ep01, ep12, ep13, refs main),
  else from file mtimes and the note says `ts:mtime`; `source='backfill'`; a done unit with no
  verdict file is noted `grandfathered: no verdict file`.
- Not written without `--force`, each with its reason on the line: a folder outside the unit
  grammar, a live run (a `started` with no terminal event inside 6 h), a hand-signed verdict
  (a signer that is not `judge:...`), a published unit whose qc file is missing or did not pass.
- `analysis`, `screenplay`, `trailer` declare no `out:` in the registry, so nothing on disk answers
  for them: no rows.  They stay on the events (C2 writes their rows from here on).
